Context & Motivation

The Problem with Traditional Coding Platforms

01

Passive & Static Learning

Platforms like LeetCode leave students stuck on test case failures without guidance. When looking at solutions, the answer is spoiled completely, impairing algorithmic retention.

02

No Adaptive Guidance

Students solve random problems without diagnosing their core weaknesses (e.g. Dynamic Programming state transitions vs. Graph traversals), leading to inefficient practice cycles.

03

Heavy Infrastructure Barriers

Most online judges require heavy multi-node container clusters or external services, making self-hosted deployment and localized team training nearly impossible.

💡 Our Objective: Create an all-in-one competitive arena that adapts to each user's skill gaps and guides them with Socratic AI hints.
Solution Overview

Coding Arena: Key Value Pillars

🎯

Diagnostic Skill Assessment & Radar Profiling

Initial 8-question conceptual evaluation across 8 algorithmic domains. Mathematically seeds a dynamic proficiency profile visualised on an interactive radar chart.

🤖

Socratic AI Coding Guide (Spoiler-Free)

Real-time submission diff inspector. Delivers conceptual hints, identifies edge case flaws, and encourages problem-solving without revealing code solutions.

⚡

Multi-Language Online Judge Sandbox

In-browser IDE supporting JavaScript, Python, C++, and Java with process isolation, strict time-limit (TLE) enforcement, and automated sample/hidden test execution.

🏆

Live Tournament Contests & Leaderboards

Real-time ICPC-style scoring, countdown clocks, penalty calculations (+20 min per failed attempt), and dynamic global Elo ratings.

Rich catalog of 75 hand-crafted algorithmic challenges across Arrays, Trees, Graphs, DP, and Greedy.

Member 1 Deep Dive

Frontend Engineering & Coding Arena Workspace

Split-Screen IDE Workspace

Designed a reactive two-pane layout. The left pane renders rich problem statements, constraints, and test scenarios. The right pane provides syntax templates for 4 languages with real-time editing.

Interactive Execution Terminal

Enables sample test case execution alongside custom input tabs. Parses execution runtime in milliseconds, returns colored status badges (Accepted, Wrong Answer, TLE), and displays stdout logs.

Skill Radar Chart Visualization

Constructed SVG polygon radar mathematics in React. Projects normalized 0–100 scores across 8 topics into 2D canvas coordinates, highlighting strength/weakness boundaries.

Client-Side Security & Interceptors

Axios request interceptors inject bearer tokens; response interceptors automatically handle expired sessions, providing seamless auto-redirects.

Viva Defense: Split-pane reactivity • State lifecycles • Optimistic UI updates • Mobile responsiveness
Member 2 Deep Dive

Core Backend & Zero-Config Dual Database Engine

Dual-Mode Embedded Database Engine

Architected a zero-dependency document store. If MongoDB is unreachable, it boots an in-memory JSON engine that serializes to disk, supporting Mongoose-compatible query chains (.find(), .sort(), .limit(), $in, $nin).

JWT & Cryptographic Security Layer

Protected authentication routes with bcrypt salted hashing (10 rounds) and stateless JSON Web Tokens. Created role-based authorization for admin database monitoring.

Real-Time Tournament & Scoring Controller

Built ICPC-standard tournament scoring: computes penalty time (submission minute + 20 min per failed attempt), ranks competitors dynamically, and manages contest countdown states.

Production Middleware Pipeline

Configured Helmet HTTP headers, CORS whitelisting, rate limiting against DDoS brute force attacks, and centralized asynchronous error handling.

Viva Defense: Query proxying • Fallback persistence • Bcrypt salting • Token expiration • API security
Member 3 Deep Dive

Online Judge Sandbox & Multi-Language Compiler

Sandboxed Execution Environments

Runs JavaScript inside Node.js vm.createContext with stripped globals (no process, fs, require). Spawns isolated OS child processes with memory bounds for Python, C++, and Java.

TLE Protection & Resource Limits

Implements strict 2000ms execution deadlines. If an untrusted algorithm enters an infinite loop, the sandbox terminates the process and emits a Time Limit Exceeded (TLE) verdict.

Output Normalization & Diffing

Normalizes whitespace, line endings (\r\n vs \n), and JSON array formatting. Guarantees semantic equivalence between user stdout and canonical expected outputs without false formatting rejects.

75-Problem Curated Test Suite

Constructed full test suites (both public sample cases and hidden stress tests) across 8 algorithmic domains, complete with starter templates in JS, Python, C++, and Java.

Viva Defense: Sandbox escapes prevention • Child process IPC • Compilation vs Interpretation • Time measurement
Member 4 Deep Dive

Socratic AI Guidance & Adaptive Recommendation Engine

Socratic AI Guidance (Spoiler-Free)

Integrated LLM API with prompt guardrails. Inspects failing submissions, detects algorithmic pitfalls (e.g. O(N^2) complexity, unhandled edge cases), and responds with intuitive hints without revealing solution code.

Weakness-Targeted Recommendation Pipeline

Parses user's SkillProfile, sorts topics ascending by proficiency, filters out solved challenges ($nin), and returns prioritized tasks with difficulty scaling (Easy if <40%, Medium if 40-70%).

Diagnostic Scoring Algorithm

Mathematical scoring formula: Score = round(25 + Accuracy * 65), calibrated between 15% and 95%. Dynamically labels topics <50% as 'Weaknesses' and assigns lowest score as recommendedFocus.

Adaptive Recommendation Feedback

Generates personalized reasoning for every problem: e.g. "Recommended because your proficiency in Dynamic Programming is 25%. Solving this will strengthen state transitions."

Viva Defense: Prompt engineering guardrails • Heuristic ranking • Cold start problem • Mathematical calibration

Engineering Challenges

Key Hurdles Solved During Development

Challenge 1

Untrusted Code Safety & Infinite Loops

Solution: Enclosed script execution within isolated contexts with hard execution timers (2000ms) and removed system call primitives, preventing CPU exhaustion and file deletion.

Challenge 2

Zero-Config Portability Without Local MongoDB

Solution: Developed an in-memory Mongoose proxy layer with JSON disk persistence. Evaluates MongoDB expressions ($nin, $in, $regex) without external database services.

Challenge 3

Socratic AI Prompt Engineering (No Spoilers)

Solution: Implemented strict system guardrails on the LLM API preventing code dumps (>3 lines). Guides students conceptually based on diff analysis of their failed test cases.

Challenge 4

Catalog Expansion to 75 Challenges & LAN Sharing

Solution: Built modular seed extensions with dynamic slug upserting so new problems merge automatically. Bound Vite to 0.0.0.0 for seamless mobile testing across local Wi-Fi.

Robust handling of compile errors, network dropouts, and rate throttling.
